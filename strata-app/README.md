# Strata Tycoon: Android app

This folder wraps the web game in [`../idle`](../idle) as a native Android app using [Capacitor](https://capacitorjs.com). Make the game changes in `idle/`; this folder only packages them.

| Path | What it is |
|---|---|
| `capacitor.config.json` | App ID `io.github.rjcoluccio.stratatycoon`, name, colours |
| `scripts/build-www.mjs` | Copies `../idle` into `www/` (the app's bundled files) |
| `android/` | The native Android Studio project (generated by Capacitor, then customised) |
| `assets/` | Source art: icon, splash, Play Store feature graphic and 512px icon |
| `scripts/make-art.cjs` | Redraws the source art; `npm run icons` regenerates every Android size |
| `../.github/workflows/android.yml` | Builds the app on GitHub on every push |

## Get a build without installing anything

Every push that touches `idle/` or `strata-app/` runs the **Android build** workflow (GitHub repo → **Actions** tab).

- **Debug APK** (always built): download the `strata-tycoon-debug-apk` artifact, unzip it, copy the `.apk` to your Android phone and open it to install. You'll need to allow "install unknown apps" for your file manager. Use this to playtest.
- **Release AAB** (built once signing is set up, below): `strata-tycoon-release-aab-vN`. This is the file you upload to Google Play.

## One-time setup: your upload key

Google Play needs every release signed with *your* key. Create it once and **back it up somewhere safe**: you sign every future update with it. (With Play App Signing, Google can reset a lost upload key, but it takes a support request and some days.)

1. Create the key. With [Android Studio](https://developer.android.com/studio): *Build → Generate Signed App Bundle → Create new…*. Or with any Java install:
   ```bash
   keytool -genkeypair -v -keystore upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
   ```
2. Base64-encode it:
   - macOS / Linux: `base64 -i upload.jks | tr -d '\n' > upload.b64` (on Linux, `base64 -w0 upload.jks > upload.b64`)
   - Windows PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("upload.jks")) > upload.b64`
3. In GitHub: **repo → Settings → Secrets and variables → Actions → New repository secret**, add:
   | Secret | Value |
   |---|---|
   | `ANDROID_KEYSTORE_BASE64` | contents of `upload.b64` |
   | `ANDROID_KEYSTORE_PASSWORD` | the keystore password |
   | `ANDROID_KEY_ALIAS` | `upload` (or whatever alias you used) |
   | `ANDROID_KEY_PASSWORD` | the key password (often the same as the keystore password) |
4. **Actions → Android build → Run workflow.** A signed AAB appears as an artifact.

Never commit `upload.jks` or `upload.b64`. This repo is public.

## Publishing on Google Play

1. **Developer account:** sign up at <https://play.google.com/console> (one-time US$25 fee, plus identity verification).
2. **Create app:** name *Strata Tycoon*, type *Game*, *Free*.
3. **Store listing** (files are in `assets/`):
   - App icon: `play-icon-512.png`
   - Feature graphic: `feature-graphic.png` (1024×500)
   - Phone screenshots: at least 2. Take them from the debug APK on your phone.
   - Short description (80 chars): *Drill through alien planets, haul ore, upgrade rigs and launch to richer worlds.*
4. **App content:**
   - Privacy policy URL: `https://rjcoluccio.github.io/idle/privacy.html`
   - Ads: *No*. Data safety: *No data collected or shared*.
   - Content rating questionnaire: no violence or gambling, so expect *Everyone / PEGI 3*.
   - Target audience: pick 13+ unless you want to opt into the stricter Families policy.
5. **Testing requirement (new personal accounts):** before production, Google requires a **closed test with at least 12 testers opted in for 14 continuous days**. Upload the AAB to *Testing → Closed testing*, invite friends by email, and have them install it from the opt-in link.
6. **Production:** after the closed test, apply for production access in the console, then promote the release.

For each update: push changes, wait for the workflow, then upload the new AAB. The version code auto-increments with the workflow run number.

## Working locally (optional)

Needs Node 22+, and Android Studio for running on an emulator or device.

```bash
cd strata-app
npm install
npm run sync              # copy ../idle into the app and update the Android project
npx cap open android      # open in Android Studio, then press Run
```
