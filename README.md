# RJC Arcade

A retro arcade cabinet in the browser, hosted on GitHub Pages. Plain HTML/CSS/JS, no build step.

- **Meteor Dash**: dodge falling rocks, grab gems
- **Byte Stacker**: time your drops, overhang gets chopped
- **Reflex Grid**: hit green tiles, never red
- **Strata Tycoon** (`/idle/`): an idle drilling game with offline earnings and prestige. Design notes in [`idle/DESIGN.md`](idle/DESIGN.md)
- **Tidepool Solitaire** (`/solitaire/`): peak-style solitaire with a reef-restoration meta game. Design notes in [`solitaire/DESIGN.md`](solitaire/DESIGN.md)

Both games are also packaged as Android apps (`strata-app/`, `tidepool-app/`), built by the **Android build** GitHub Actions workflow.

Insert a coin (`C`), press start (`Enter`), and chase the high score. Scores are saved in your browser.
